# local.bptable — таблица распределения для БП и списков

## Установка / обновление
1. Распаковать в `/home/bitrix/www/local/modules/local.bptable/`.
2. Новая установка: Marketplace → Установленные решения → «Таблица распределения для БП».
   Обновление: `php -f tools/upgrade.php` (из папки модуля). Данные не трогает.
3. Проверка: `php -f tools/selftest.php` → `ALL OK`.

`upgrade.php` / установщик:
- регистрирует типы свойств инфоблока `S:LocalBpTable`, `S:LocalBpTablePayroll`, `S:LocalBpTablePayment`;
- регистрирует UF-тип `local_bptable` (CRM);
- копирует JS в `/local/js/local.bptable/` и действие БП в `/local/activities/lbptablebuildactivity/`.

## Связка с AI Lab 1.2
Поле ответа сценария типа «Таблица (строки с колонками)» с кодами колонок
`period, division, organization, project, expense, employee, amount` отдаёт в БП JSON `{"rows":[…]}` —
его можно сразу присвоить переменной типа «Таблица распределения: ЗП» (`{=A…:payment_table}`)
или подать в «Таблица распределения: подготовить».

## Схема БП (список iblock_32)
1. **AI Lab: запрос к ИИ** — ответ по схеме `docs/ai-response-schema.json`, целиком в строковую переменную/результат.
2. **Таблица распределения: подготовить** — Источник = `{=…ответ ИИ…}`, Набор колонок, «Записать в переменную» = `PaymentTable`.
   Возвращает: Таблица (JSON), Количество строк, Итого, Ячеек без ID, Сводка (текст для уведомлений).
3. **Запрос доп. информации** — поле `PaymentTable` (тип «Таблица распределения: ЗП»), значение по умолчанию **пустое** →
   задание само подставит текущее значение переменной.
4. **Изменение документа** — свойство таблицы = `{=Variable:PaymentTable}`.

Шаг 2 можно пропустить, если ответ ИИ пишется прямо в `PaymentTable`: редактор сам нормализует вход при открытии задания.

## Формат хранения (v1)
```json
{"v":1,"preset":"payroll","rows":[{"period":"2026-09-30T23:59:59+05:00",
 "division":{"id":13,"title":"DPI","code":"dpi"},
 "organization":{"id":1,"title":"ТОО …","code":"<UF_ORGANIZATION_ID_API_1C>"},
 "project":{"id":458,"title":"Digital Kazdream","code":"<UF_CRM_20_ID_FIN_HUB>"},
 "expense":{"id":80,"title":"…","code":"<UF_CRM_21_ID_FIN_HUB>"},
 "employee":{"id":2759,"title":"Адлет Касенов"},
 "amount":"150000.00"}]}
```
- `id: null` + `title` — значение без привязки к справочнику (жёлтое). Управляется `Config::KEEP_TEXT_WITHOUT_ID`.
- Вход принимает и упрощённый формат: строки вместо объектов, русские ключи, «150 000,00», «30.09.2026», ```json-обёртку.
- Число в ref-ячейке = ID, строка = текст.
